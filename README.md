# AgriMarket Flow

## Project Overview

AgriMarket Flow is an academic database project focused on managing the distribution of agricultural products from farmers to retailers.

The project organizes information about farmers, products, retailers, transporters, orders and deliveries using a relational database.

It was developed as a group project using Microsoft SQL Server.

## Technologies Used

- **Microsoft SQL Server** – Database management system.
- **SQL (T-SQL)** – Database creation, queries and data manipulation.
- **SQL Server Management Studio (SSMS)** – Environment used to write and manage SQL scripts.
